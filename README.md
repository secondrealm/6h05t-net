# 6h05t.net

**Our fight is binary. Our future is not.**

[Website](https://6h05t.net) · [Second Realm](https://secondrealm.net)

An experimental speculative fiction and worldbuilding project created by Second Realm in 2023, exploring identity, surveillance, technological control, and digital resistance.

This repository contains the source code and archival content for 6h05t.net, including a 16-chapter serialized story, an unpublished novel concept, and the original worldbuilding documentation.

## Overview

6h05t began in 2023 with *The Last Stand*, an unpublished science fiction concept exploring a dystopian future in which the Remnants, a faction of human-computer hybrids, seek control over society.

After developing the fictional world, I worked backward to explore its origins. That became *The Society*, a 16-chapter serialized prequel published through the Creative Bytes newsletter in July 2023.

In 2026, I revisited the project and built this website to preserve the fiction, worldbuilding, and creative process.

## Features

- **Serialized fiction:** 16 chapters of *The Society* with dedicated reading pages and chapter navigation.
- **Novel development:** Original concept, synopsis, and four-act outline for *The Last Stand*.
- **Worldbuilding archive:** Fictional setting, factions, characters, themes, and original working notes.
- **Creative process:** Documentation of narrative experimentation and human–AI collaboration.
- **Responsive design:** Dark, minimalist interface with pixel typography and custom imagery.
- **Static architecture:** Lightweight HTML, CSS, and JavaScript without a frontend framework.


Replace `OWNER/REPO` with the repository's actual GitHub path.

Open `http://localhost:8080` in your browser.

## Human–AI collaboration

This project documents two separate periods of collaboration with generative AI.

**2023: Fiction and worldbuilding**

I used generative AI to explore narrative structures, develop characters, prototype fictional systems, and experiment with speculative worldbuilding through iterative dialogue.

**2026: Website design and development**

I collaborated with ChatGPT to design and develop this website, including its interface, chapter reader, archival structure, and documentation.

The creative direction, source material, editorial decisions, and final responsibility remained mine throughout.

In other words, I used AI to build a website documenting how I used AI to build a fictional world.

## Project status

The original fiction was developed and published in 2023. The website was created in 2026 as a retrospective archive of the work and its development.

The repository is maintained primarily for archival preservation and occasional improvements.
